# RELYRA — مطابقة المواصفات مع كود main

**مرجع الحالة:** `main`، والشرح التفصيلي في [جرد الفرع الرئيسي](MAIN_BRANCH_AUDIT_AR.md).  
**قاعدة التقييم:** وجود اسم أو شاشة أو نموذج بيانات لا يعني اكتمال الوظيفة. يجب التمييز بين كود موجود، اختبار وحدة، اختبار تكامل، وتشغيل فعلي على أجهزة مستقلة.

الحالات:
- **موجود:** الوظيفة الأساسية موجودة في المصدر.
- **جزئي:** جزء من الوظيفة موجود، وتوجد قيود أو اختبارات/تكاملات ناقصة.
- **غير منفذ:** لا يوجد تنفيذ فعلي بعد.

| # | بند المواصفات | الحالة على main | الملاحظات الدقيقة |
|---:|---|---|---|
| 1 | تعريف المشروع | جزئي | تطبيق Android أصلي؛ المنصة اللامركزية الشاملة لم تكتمل. |
| 2 | الرؤية والأهداف | جزئي | الهوية والرسائل والتشفير والنقل والملفات موجودة؛ المزامنة والمكالمات وMesh الكامل غير منفذة. |
| 3 | المبادئ الأساسية | جزئي | تخزين محلي وتشفير قبل النقل؛ بعض الخدمات الاختيارية تعتمد على مشغلي relay/gateway خارجيين. |
| 4 | الوظائف الرئيسية | جزئي | رسائل ومجموعات وMLS ومجتمعات وملفات وتشخيص؛ المكالمات وتعدد الأجهزة وMesh العالمي غير منفذة. |
| 5 | الهوية الرقمية | موجود | Ed25519 محلية، بطاقات اتصال موقعة، QR/رابط ومفتاح استرداد؛ إدارة عدة أجهزة غير منفذة. |
| 6 | اكتشاف المستخدمين | جزئي | إضافة يدوية وQR/رابط، واكتشاف حضور عبر بوابة DHT؛ دليل عام موزع بالكامل غير مكتمل. |
| 7 | المحادثات | موجود | محادثات فردية، حالات إرسال وتسليم، صندوق دائم وإشعارات؛ بعض أدوات إدارة الرسائل المتقدمة قد لا تكون ضمن المواصفات المنفذة. |
| 8 | Delivery Engine | موجود | حفظ الرسالة قبل النقل، ACK، retry/backoff، إزالة التكرار ومعرف ثابت لإعادة المحاولة. |
| 9 | أدوات الرسائل | جزئي | أدوات المحادثات الأساسية موجودة؛ لا تعتبر أي وظيفة غير ظاهرة/غير موصولة في UI منجزة. |
| 10 | المجموعات | جزئي | مجموعات قديمة بتشفير فردي لكل عضو، ومجموعات MLS جديدة عبر OpenMLS؛ تنسيق Proposal متعدد المشرفين والتوافق بين أجهزة مستقلة ناقص. |
| 11 | المجتمعات | جزئي | manifests ودعوات وعضوية ومنشورات موقعة وإشراف وبلاغات وسجل تدقيق. محتوى المنشور نص صريح على خدمة الاكتشاف، والفهرس محلي Pebble وليس موزعًا عبر DHT. |
| 12 | نقل الملفات | جزئي | Blossom مع تشفير محلي، تنزيل Range واستيثاق الحجم/SHA-256؛ رفع مجزأ قابل للاستكمال غير منفذ. |
| 13 | المكالمات | غير منفذ | WebRTC DataChannel فقط؛ لا MediaTracks أو دورة مكالمة صوت/فيديو. |
| 14 | Vault | موجود | خزنة ملفات محلية مشفرة مع فحص/تصدير؛ مشمولة في أرشيف النسخ الاحتياطي الحالي. |
| 15 | Browser | جزئي | WebView داخلي محدود بسياسات محافظة؛ ليس متصفحًا كاملًا ولا Tor browser. |
| 16 | إدارة المستندات | جزئي | قارئ PDF محلي للقراءة فقط وأدوات فحص؛ لا محرر مستندات متكامل. |
| 17 | QR | موجود | تبادل بطاقة الاتصال/الهوية عبر QR والرابط. |
| 18 | Offline Communication | جزئي | Bluetooth Classic للأجهزة المقترنة وWi-Fi Direct وNearby LAN؛ لا BLE Mesh أو تعدد قفزات أو Store-and-Forward عبر طرف ثالث. |
| 19 | Adaptive Network Engine | جزئي | موجّه يختار المسارات المتاحة؛ لا سجل شامل لكل محاولة ومسار وسبب فشل في main. |
| 20 | P2P | جزئي | WebRTC P2P DataChannel وإشارات موقعة وموافقة على العرض؛ لا صوت/فيديو. |
| 21 | الاتصال المباشر والاكتشاف | جزئي | Go/libp2p Kademlia DHT وHTTPS gateway وPresence وcoturn config/credentials؛ Android لا يعمل كـlibp2p host، والاختبارات متعددة العقد وTURN الحقيقي ناقصة. |
| 22 | Community Nodes | غير منفذ | لا إدارة عقد موارد مجتمعية مستقلة. |
| 23 | Nostr | موجود | WSS relay قابل للإعداد، توقيع والتحقق من الأحداث وإعادة الاتصال. |
| 24 | Blossom | جزئي | رفع ciphertext وتنزيله والتحقق منه واستكمال تنزيل Range؛ لا استكمال بايتي للرفع. |
| 25 | Tor | جزئي | لا يوجد Tor daemon مدمج؛ لا تعتبر أي إعداد وكيل خارجي خدمة Tor كاملة داخل التطبيق. |
| 26 | Server Studio | غير منفذ | لا لوحة مدمجة لإدارة نشر وتشغيل خدمات RELYRA. |
| 27 | Interoperability | غير منفذ | لا جسور Matrix أو XMPP/OMEMO. |
| 28 | التشفير والأمان | جزئي | X3DH/Double Ratchet وOpenMLS مع تخزين SQLCipher؛ تنسيق Proposal/fork، تدقيق مستقل وتحقق الأجهزة المستقلة ما زالت مطلوبة. |
| 29 | مكافحة الإزعاج | جزئي | حظر/كتم/slow-mode/allow-post وبلاغات وسجل تدقيق في خدمة المجتمع؛ لا تعتبر نصوص المحتوى مشفرة طرفيًا. |
| 30 | التخزين المحلي | موجود | Room + SQLCipher ومخازن ملفات محلية، وملف MLS منفصل مشفر. |
| 31 | مزامنة الأجهزة | غير منفذ | لا تسجيل/اعتماد/إلغاء أجهزة ولا مزامنة آمنة متعددة الأجهزة. |
| 32 | Backup/Restore | جزئي | الأرشيف الحالي يضم قاعدة البيانات وVault وinbox/outbox وMLS وتفضيلات الشبكة والخوادم؛ اختبارات التكامل الكاملة للاستعادة والانهيار واتساق Room/MLS والمigrations الفعلية ما زالت ناقصة. |
| 33 | UI/UX | جزئي | واجهات المحادثات والمجموعات والمجتمعات والشبكة والتشخيص بالعربية والإنجليزية؛ بعض الوظائف القادمة لا تملك واجهات بعد. |
| 34 | لوحة التحكم | جزئي | شاشات حالة وتشخيص موجودة؛ لا لوحة تشغيل كاملة لخدمات أو أجهزة متعددة. |
| 35 | تكامل Android | موجود | Keystore وRoom وWorkManager والإشعارات وصلاحيات الشبكات والاتصال القريب. |
| 36 | Accessibility | جزئي | موارد عربية/إنجليزية وRTL؛ تدقيق شامل لقارئات الشاشة والتباين وتكبير النص لم يكتمل. |
| 37 | Plugin SDK | غير منفذ | لا SDK أو runtime مع sandbox وصلاحيات للإضافات. |
| 38 | Local API | غير منفذ | لا API محلية عامة مصادق عليها. |
| 39 | الأدوات المرافقة | غير منفذ | لا Desktop/Node/Developer Studio. |
| 40 | التشخيص | جزئي | فحوص قاعدة البيانات والشبكة والموارد وتقارير منقحة؛ تشخيص كل محاولة routing ما زال ناقصًا. |
| 41 | إدارة الموارد | موجود | قراءات موارد التطبيق وCPU/شبكة/مساحة التخزين ضمن حدود Android المتاحة. |
| 42 | المعمارية | جزئي | تقسيم داخلي إلى حزم Kotlin وخدمة Go ومكتبة Rust؛ ليس كل مكون وحدة مستقلة. |
| 43 | التقنيات | جزئي | Kotlin/Compose/Room/SQLCipher/OpenMLS/Rust-JNI/Nostr/Blossom/WebRTC DataChannel/libp2p Go؛ لا Android libp2p host أو MediaTracks. |
| 44 | الهيكل البرمجي | جزئي | بنية مصدر فعلية؛ لا تُنشأ مجلدات فارغة فقط لمطابقة قائمة المكونات. |
| 45 | مراحل البناء | جزئي | CI يبني Android ويختبر JVM وGo وRust؛ نجاح البناء لا يغلق اختبارات التكامل أو الأجهزة. |
| 46 | الاختبارات | جزئي | اختبارات وحدات وتكامل جزئية موجودة؛ RestoreApplier end-to-end، migrations fixtures، DHT متعدد العقد وTURN الحقيقي والتوافق بين الهواتف ما زالت ناقصة. |
| 47 | اعتماد المراحل | جزئي | المرحلة الأولى والثانية فيها تنفيذ واسع؛ لا تعلن إغلاق اختبارات المرحلة الأولى وتنسيق MLS حتى اجتياز البنود المتبقية. |
| 48 | بنية المصدر المفتوح | موجود | مستودع GitHub وCI وApache-2.0؛ SBOM وreproducible builds وتدقيق سلسلة التوريد ما زالت مطلوبة. |
| 49 | الترخيص والنشر | جزئي | Apache-2.0 موجود؛ مراجعة تراخيص الاعتماديات وتوقيع الإصدارات لم تكتمل. |
| 50 | شروط التشغيل | جزئي | مبدأ عدم وجود أزرار وهمية موثق؛ يجب ربط كل ميزة مستقبلية بواجهة وخدمة واختبار قبل إعلانها. |

## ترتيب التنفيذ الحالي

1. تثبيت حالة البناء والتحقق من main.
2. تحديث جرد main والتوثيق.
3. إغلاق اختبارات تكامل المرحلة الأولى دون إعادة بناء BackupManager/BackupArchive.
4. إنهاء تنسيق MLS المتبقي فوق OpenMLS الموجود.
5. تنفيذ المراحل 4–10 كاملة وربط أدواتها وخدماتها وواجهاتها بالتطبيق.
6. بعد ذلك فقط: استكمال نواقص المرحلة الثالثة (DHT الموزع، دليل المجتمعات، TURN، تشخيص المسارات وStore-and-Forward).

تفاصيل كل بند وحدود الاختبار موجودة في [جرد main](MAIN_BRANCH_AUDIT_AR.md) و[خطة التنفيذ](IMPLEMENTATION_PHASES_AR.md).
