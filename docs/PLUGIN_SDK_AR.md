# RELYRA — حزمة تطوير الإضافات (Plugin SDK)

**الحالة:** منفّذ (إضافات بيانات فقط) · مُختبر (اختبارات Node وJUnit في المستودع) · لم يُتحقق منه على هاتف حقيقي.

إضافات RELYRA عبارة عن **ملفات JSON** وليست كودًا. لا تحتوي على DEX أو كود أصلي أو سكربتات أو أوامر shell. يتحقق التطبيق من الحزمة عند التثبيت، ويطلب موافقة المستخدم على الصلاحيات، ويعيد فحص كل إجراء عند تشغيله.

## صيغة الحزمة

نوع MIME: `application/vnd.relyra.plugin+json` · الحجم الأقصى: 256 كيلوبايت · إصدار المخطط: `1`

| الحقل | القاعدة |
|---|---|
| `schemaVersion` | يجب أن يكون `1` |
| `id` | `[a-z0-9][a-z0-9._-]{2,63}` |
| `name` | من 1 إلى 80 حرفًا |
| `version` | بصيغة `MAJOR.MINOR.PATCH` مثل `1.0.0` |
| `description` | اختياري، حتى 500 حرف |
| `permissions` | اختياري، من القائمة المسموحة أدناه، بلا تكرار |
| `actions` | من 1 إلى 20 إجراءً، معرّفاتها فريدة وتطابق `[A-Za-z0-9_-]{1,40}` |

## الصلاحيات

- `clipboard.write` — يحتاجها الإجراء `copy_text`.
- `external.open` — يحتاجها الإجراء `open_url`.

## أنواع الإجراءات

- `notice` — يعرض رسالة داخل التطبيق. الحقل `text` حتى 2000 حرف.
- `copy_text` — ينسخ `text` (حتى 4000 حرف) إلى الحافظة. يحتاج `clipboard.write`.
- `open_url` — يفتح `url` بعد تأكيد المستخدم. يجب أن يبدأ بـ `https://` بدون بيانات دخول وبطول حتى 2048. يحتاج `external.open`.

لكل إجراء أيضًا `id` و`title` (من 1 إلى 80 حرفًا).

## أدوات المطور (بدون هاتف)

من مجلد `companion/node`:

```bash
node bin/relyra.mjs plugin init --id dev.my-plugin --name "My plugin" --output my-plugin.json
node bin/relyra.mjs plugin validate my-plugin.json
```

أمثلة جاهزة في `plugins/examples/`. المدقق في `companion/node/src/plugin-sdk.mjs` يستخدم نفس حدود تطبيق Android (`PluginRuntime` و`PluginSdk`)، فأي حزمة يقبلها `validate` يقبلها التطبيق.

## فحص الإضافة داخل التطبيق

افتح **الإعدادات ← أدوات المطورين ← حزمة تطوير الإضافات**. يمكنك فحص ملف إضافة بنفس المدقق الذي يستخدمه التطبيق عند التثبيت، وحفظ إضافة نموذجية لتبدأ منها، وفتح مدير الإضافات لتثبيتها.

## ما لا تستطيع الإضافات فعله

لا تقرأ الرسائل أو المفاتيح أو قاعدة البيانات، ولا ترسل طلبات شبكة، ولا تنفذ كودًا، ولا تستدعي Local API. تحميل الكود (DEX أو أصلي أو JavaScript) **مخطط فقط** وغير منفذ، ويحتاج بيئة عزل ومراجعة أمنية مستقلة.
