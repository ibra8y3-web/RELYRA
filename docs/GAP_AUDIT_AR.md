## جزئي (حسب docs/IMPLEMENTATION_STATUS.md وتأكيد الكود)
Blossom بلا رفع مجزأ/استكمال · MLS بلا تنسيق مشرفين متعددين/تعارض Commit · مزامنة الأجهزة بلا حالة MLS ومفاتيح الجلسات · Server Studio على الكمبيوتر فقط · Local API بلا إدارة مجموعات · ثغرة DHT GO-2024-3218 مفتوحة · وحدة `app` واحدة و`MainViewModel` = 1257 سطرًا.

## ما أُضيف في هذه الدفعة
- `core/documents/CsvParser.kt` — قارئ CSV (RFC 4180، اكتشاف الفاصل، BOM، Unicode، حد للصفوف والخلايا، بحث).
- `core/documents/XmlTreeParser.kt` — محلل XML آمن: يرفض DOCTYPE (لا XXE ولا توسيع كيانات)، حدود للعمق والعقد والحجم.
- `test/.../CsvParserTest.kt` — 5 اختبارات.
- ربط CSV وXML بشاشة الأدوات (`ToolsScreen.kt`): تبويبان جديدان مع بحث وتصفح بالصفحات وطي/فتح عناصر XML، وملفا نصوص `strings_documents.xml` (إنجليزي وعربي).
**الحالة: Implemented + Integrated في شاشة الأدوات. غير مبني ولا مختبر على جهاز. الفتح من مدير الملفات/Vault مباشرة لم يُربط بعد.**
