# واجهة RELYRA المحلية (Local API)

**الحالة:** منفذة · الاختبارات مكتوبة (`LocalApiServerTest` بسوكتات JVM) لكنها لم تُشغَّل بعد على مترجم Kotlin · لم يُتحقق منها على جهاز.

شغّلها من **الإعدادات ← التكاملات ← Local API**. تستمع على `127.0.0.1` فقط، بمنفذ عشوائي ورمز Bearer ينتهي بعد 15 دقيقة ويختفي عند إيقاف التطبيق. يجب أن تستخدم الطلبات `Host` المحلي، وألا تحمل `Origin` من متصفح، والحد 60 طلبًا في الدقيقة.

## نقاط الوصول

| الطريقة والمسار | الصلاحية | الغرض |
|---|---|---|
| `GET /v1/health` | بدون | حالة العملية |
| `GET /v1/diagnostics` | بدون | عدادات منقحة |
| `GET /v1/openapi.json` | بدون | العقد بصيغة قابلة للقراءة الآلية |
| `GET /v1/identity` | `identity.read` | الاسم المعروض والمعرّف العام |
| `GET /v1/contacts` | `messages.send` | معرّفات جهات الاتصال وأسماؤها (المحظورون مخفيون) |
| `GET /v1/groups` | `messages.send` | معرّفات المجموعات وأسماؤها |
| `POST /v1/messages` | `messages.send` | الجسم `{"to": "<المعرّف العام>", "text": "..."}` |
| `POST /v1/groups/messages` | `messages.send` | الجسم `{"groupId": "...", "text": "..."}` |

صلاحية `messages.send` **متوقفة افتراضيًا** وتُفعَّل من التطبيق قبل إنشاء الرمز. الإرسال يمر عبر محركي التسليم والمجموعات نفسيهما: التشفير الطرفي، ومعرّف رسالة جديد لكل إرسال، وإعادة المحاولة بالمعرّف نفسه، وقواعد الحظر. الرد `202` يعني أن الرسالة وُضعت في الطابور وليس أنها وصلت.

حدود POST: `Content-Type: application/json` و`Content-Length` لا يزيد عن 8192 بايت، والنص حتى 6000 حرف، و20 إرسالًا في الدقيقة. رموز الأخطاء: `403` (الصلاحية متوقفة أو جهة الاتصال محظورة)، `404` (جهة اتصال أو مجموعة غير معروفة)، `409` (لا يوجد مفتاح تشفير بعد)، `413` و`415` و`422` و`429`.

```bash
curl -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"to":"CONTACT_PUBLIC_ID","text":"hello"}' http://127.0.0.1:$PORT/v1/messages
```

## غير متاح عبر الواجهة

إنشاء المجموعات، وإضافة الأعضاء أو إزالتهم، والمرفقات، وقراءة سجل الرسائل، وقراءة المفاتيح أو قاعدة البيانات: **غير موجودة (Missing)** بالتصميم أو لم تُبنَ بعد. أي برنامج على الهاتف يحصل على الرمز يستطيع الإرسال طوال تشغيل الواجهة، فأوقفها عندما لا تحتاجها.
