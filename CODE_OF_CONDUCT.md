# Code of Conduct

RELYRA is a privacy-focused project, and people who contribute to it or use it should feel safe doing so.

## Expected behavior

- Be respectful and assume good faith. Disagree about technical choices without attacking people.
- Give and accept constructive feedback, especially in code review and security discussions.
- Respect other people's privacy. Never publish private messages, keys, tokens, device identifiers or personal details, yours or anyone else's.
- Report security problems through the private process in `SECURITY.md`, not in public issues.

## Unacceptable behavior

- Harassment, threats, discrimination or personal attacks.
- Publishing someone's private information without permission.
- Sustained disruption of discussions, or repeatedly pushing changes that others have declined with a documented reason.

## Enforcement

Maintainers may edit or remove comments, issues and contributions that break this code, and may restrict participation of people who repeatedly do so. To report a concern, contact the maintainers using the private address in `SECURITY.md` and mark the message "Code of Conduct". Reports are handled confidentially.

This code applies in project spaces (repository, issues, discussions) and when someone represents the project in public.
